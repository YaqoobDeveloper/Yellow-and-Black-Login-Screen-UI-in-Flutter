# Yellow and Black Login Screen UI in Flutter 💛🖤

A bold **yellow and black login screen** built with Flutter, featuring a sunny yellow panel with a curved bottom edge, rounded pill fields, a black **LOGIN** button and a yellow **SIGN UP** button on a dark background, all in the friendly Quicksand font.

The UI is split into small, reusable components, the same way you would structure a React Native app.

## ✨ Features

- 💛 Yellow panel with a smooth curved bottom edge
- 🖤 Dark lower section with an **OR** divider and **SIGN UP** button
- 💊 Rounded pill fields for email / username and password
- ✅ Validation that accepts either an email or a username
- ⌨️ Press Enter on the password field to log in
- 🔤 Quicksand font with wide-spaced uppercase buttons
- 🧩 Reusable components with a barrel export (like `components/index.ts`)

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Yellow-and-Black-Login-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Yellow-and-Black-Login-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
